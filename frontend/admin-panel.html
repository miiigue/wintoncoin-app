Gestión de Base de Datos

Herramientas para mantener, limpiar y respaldar la base de datos de manera segura.

📊 Estadísticas de la Base de Datos

💾 Herramientas de Backup

Crea copias de seguridad antes de realizar cualquier operación de limpieza.

🧹 Herramientas de Limpieza

⚠️ Todas las operaciones crean un backup automático antes de ejecutarse.

🗑️ Limpiar Datos de Prueba

Elimina usuarios y publicaciones que contengan 'test', 'demo' o 'example' en el nombre.

👥 Limpiar Usuarios Inactivos

Elimina usuarios que no han tenido actividad y mantienen saldos por defecto.

📝 Limpiar Publicaciones Antiguas

Elimina publicaciones completadas que sean muy antiguas.

⚠️ Importante: Mejores Prácticas

  • ✅ Siempre se crea un backup automático antes de cada operación
  • ✅ Las operaciones respetan las restricciones de integridad de la base de datos
  • ✅ Los usuarios de plataforma nunca son eliminados
  • ✅ Solo se eliminan datos que cumplan criterios específicos de seguridad
  • ⚠️ Las operaciones son irreversibles (excepto con restauración de backup)
  • 📋 Todas las acciones quedan registradas en los logs del servidor

Zona de Peligro

Las acciones en esta sección son irreversibles y pueden causar la pérdida permanente de datos.

Reiniciar la Base de Datos

Esta acción eliminará TODOS los usuarios (excepto el de la plataforma), publicaciones, transacciones, saldos y cualquier otro dato generado. La base de datos volverá a su estado inicial. Úsese con extrema precaución.
